# sample-shop

A small pricing service with a short, real PR history, made for trying FlowControl on: add this repo in
FlowControl's Settings → Repos and its merged PRs are imported, given risk tiers, and scored as their outcomes arrive.

Set `PORT` to choose the port.

Totals are in cents: item prices times quantities, plus tax.

Some PRs here went bad on purpose: one was reverted, and two were fixed by later PRs that say which change they repair.
